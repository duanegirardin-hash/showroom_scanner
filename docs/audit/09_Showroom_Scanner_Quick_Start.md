# Showroom Scanner — Quick Start (1–2 pages)

**Print this sheet and keep it at the counter.**

## Before you start

1. Charge the phone and pair the Bluetooth barcode scanner.
2. Open **Showroom Scanner** (portrait only).
3. Wait until the app is ready to scan.
4. Select the **correct customer** before adding any items.

## Everyday order (2 minutes)

1. Tap **Create Quote** (pick customer if asked) → confirm **Create Quote**.
2. Stay on the **Scan** tab.
3. Scan barcodes **or** type **Item # / UPC** and tap **Add**.
4. Use **+** / **−** or **Edit Quantity** to adjust (steps use Minimum Order Quantity).
5. Different Product Types (Everyday, Halloween, Summer Toys, …) automatically open separate quotes.
6. To reopen a quote: **Load Quote** → tap the quote name.
7. When finished for that quote: **Export Current Quote Only** **or** from **Load Quote** → Email → **Email Current Quote Only (moves to Archive)**.

## Tabs

| Tab | Use it for |
|-----|------------|
| **Scan** | Fast scanning and quantity changes |
| **E-Catalog** | Search, filters, **Import Order**, **Export Current Quote Only**, **Export All Quotes** |
| **Archive** | Exported/emailed quotes, restore, confirm, delete |
| **Setup** | Refresh products/customers (careful), walk-order tools |

(There is no **Orders** tab in the tab bar; export/import live mainly on **E-Catalog** / **Load Quote**.)

## E-Catalog shortcuts

Chips: **New Items**, **Everyday**, **Decor & Giftware**, **Seasonal**, **Sale**, **In Order**, **In Stock Only**, **Previously Ordered Only**, **Clear Filters**.

## Email / export — what archives?

| Action | Moves to Archive? |
|--------|-------------------|
| **Email Current Quote Only (moves to Archive)** | Yes |
| **Email All Quotes for This Customer…** | Yes |
| **Email All Saved Quotes (share only — does not archive)** | **No** |
| **Export Current Quote Only** | Yes |
| **Export All Quotes** | Yes |

## Summer products (important)

- **SPRING/SUMMER - GENERAL** → Summer General quote  
- **SPRING/SUMMER - TOYS** → Summer Toys quote (separate)

## Do not

- Wrong customer + scanning  
- **Build Full Catalog Test Quote** during live selling  
- Assume Email All archives  
- Force-close during export/email  
- Clear app storage without exporting first  
- Uninstall before backing up quotes  

## If something looks wrong

1. Check customer name.  
2. Use **Load Quote** to see Active quotes.  
3. Check **Archive** if you already exported/emailed.  
4. Setup → **LOAD PRODUCTS** only if catalog seems stale (needs internet).  
5. See Troubleshooting guide for scanner/camera/pricing issues.

## Closing the day

Export or email finished quotes. Confirm important ones in **Archive** if that is your process. Quotes live on the phone until you export/email/back them up — there is no automatic cloud backup.
